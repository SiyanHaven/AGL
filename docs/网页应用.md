# 可编程网页应用

AGL 不再只有“返回同一段文本”的 HTTP 服务。`启动网页应用` 把每个真实 HTTP 请求交给
你写的处理函数，因此路由、表单、JSON API、SQLite 都能用 AGL 源码完成。

## 最小用法

```agl
函数 处理请求(请求: 映射表) -> 映射表 {
  如果 请求["路径"] 等于 "/health" {
    返回 {"状态": 200, "类型": "application/json; charset=utf-8", "内容": {"状态": "ok"}}
  }
  返回 {"状态": 404, "内容": "没有这个页面"}
}

函数 主入口() 效应 网络 {
  启动网页应用(8080, "处理请求")
}
```

处理函数名是字符串；运行时在同一个模块里查找它。`启动网页应用` 的效应是 `网络`，
所以调用它的入口必须声明 `效应 网络`。处理函数自己用到的文件 / 数据库 / 时间能力，
按普通规则声明自己的效应（例如 `效应 读写 计时`）。

第三个参数是绑定地址，可省略，默认 `127.0.0.1`：只有本机能访问，不会在启动时
悄悄把服务暴露到整个局域网。确实需要给别的设备访问时，才显式写
`启动网页应用(8080, "处理请求", "0.0.0.0")`；这时应同时考虑访问鉴权。

## 请求映射表

| 键 | 类型 | 含义 |
|---|---|---|
| `方法` | 文本 | `GET` / `POST` / `PUT` / `PATCH` / `DELETE` / `HEAD` |
| `路径` | 文本 | 已解码的路径，例如 `/api/messages` |
| `原始路径` | 文本 | 带查询串的原始请求行 |
| `查询` | 映射表 | 查询参数；同名参数取最后一个值 |
| `查询串` | 文本 | 原始查询串 |
| `Cookie` | 映射表 | 解析后的 Cookie 键值 |
| `请求体` | 文本 | 请求体原文 |
| `表单` | 映射表 | `application/x-www-form-urlencoded` 表单字段 |
| `头` | 映射表 | 请求头 |
| `内容类型` | 文本 | `Content-Type` |

## 响应映射表

| 键 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `状态` | 整数 | `200` | HTTP 状态码 |
| `类型` | 文本 | 自动判断 | `Content-Type`；不写时按内容或文件后缀推断 |
| `内容` | 任意 | `""` | 文本；映射表 / 列表自动序列化为 JSON，并默认使用 `application/json` |
| `文件` | 文本 | 无 | 要返回的文件路径；按二进制读取，自动推断 MIME，优先于 `内容` |
| `头` | 映射表 | `{}` | 额外响应头；`Content-Type` / `Content-Length` 由运行时管理 |

`文件` 路径相对服务进程的当前目录解析，可以返回 CSS、JS、图片、字体等二进制资源：

```agl
如果 请求["路径"] 等于 "/logo.svg" {
  返回 {"文件": "assets/logo.svg"}
}
```

文件路径由 AGL 代码自己决定；不要把未经校验的请求路径直接拼进 `文件`，
否则可能读到服务进程有权限访问的任意本地文件。

处理函数也可以直接返回一段文本，运行时按 HTML 响应返回。`OPTIONS` 请求由运行时处理，
并默认带 CORS 头，方便本地前端联调。异常会被运行时捕获为 `500`，不会带崩整个进程。

## 安全拼接 HTML 和 URL

用户输入不能直接拼进 HTML 或 URL。运行时提供三个纯函数：

```agl
转义HTML("<a> & b")                 // "&lt;a&gt; &amp; b"
编码URL("你好 A/B")                 // "%E4%BD%A0%E5%A5%BD%20A%2FB"
解码URL("%E4%BD%A0%E5%A5%BD")       // "你好"
```

`转义HTML` 处理 `&`、`<`、`>`、`"`、`'` 五个字符，适合拼文本节点和属性值；
`编码URL` 按 URL 组件编码，空格是 `%20`，斜杠不保留；`解码URL` 只做百分比解码，
不把 `+` 当空格（表单解析已经单独处理 `+`）。

## 一个完整案例

[`examples/zh/05_留言板网页.agl`](../examples/zh/05_留言板网页.agl) 用 AGL 写了：

- 首页 HTML；
- `GET /api/messages` 读取 SQLite 留言并返回 JSON；
- `POST /api/messages` 接收表单写入；
- `POST /api/delete` 删除留言；
- `GET /health` 健康检查。

启动：

```powershell
python -m compiler.cli run examples/zh/05_留言板网页.agl
```

打开 `http://localhost:8080`。首次启动会在当前目录创建 `留言.db`，之后数据会保留。

## 与旧服务内建的关系

- `启动HTTP(端口, 文本)`：所有请求返回同一段文本，适合最小探活；
- `启动网页应用(端口, 处理函数名, 绑定地址?)`：完整请求/响应处理，适合真正的应用；绑定地址默认回环；
- `启动待办Web(端口, 数据库路径)`：内置待办示例，保留用于旧示例兼容。

三者默认 VM 与 Python 种子后端都实现；新增应用优先使用 `启动网页应用`。
