# AGL v0.53.0 发布说明（首个发布候选）

发布日期：2026-11-15
版本：`0.53.0`
定位：**第一个可交付的 AGL 发布候选（Release Candidate）**，不是“功能已经无限完整”的 1.0。

本版同时提供可直接运行的六个中英示例、双语语言规范、GitHub 发布文件和统一后的 MCP 口径：
`agl-mcp 0.53.0` / 协议 `2024-11-05` / 10 个工具。

## 一、这一版能做什么

AGL 是一套可编译、可执行、可自举的中文/英文同构语言工具链：

```agl
#语言=中文
函数 主入口() {
  打印("你好 AGL")
}
```

- `.agl` 源码经词法、语法、类型/效应检查，生成 `.agl.ir` 与 `.agb` 字节码；
- 默认由 **AGL 自己写的自举编译器** 编译，再由自研 VM 执行；
- 运行错误回译到 AGL 源码行号；
- 保留 Python 种子编译器与 Python 后端作为显式回退；
- 支持模块、结果对象、异常、`匹配`、任务、状态快照、HTTP、FFI（白名单）等能力；
- 187 个规范内建，VM 侧全部有实现（`task` 是任务关键字，不作为普通内建计）。

## 二、安装：普通用户只装运行时

**发布包不捆绑 Python；在线安装和压缩包两种形态都支持。** 默认使用“用户 agent 工具当前调用的那个 `python`”。

本版把发布拆成两套形态：

- **普通用户运行时包**：只装 `compiler/`、`aglc/`、`spec/`、`stdlib/`、`examples/` 和预编译 `compiler/_runtime/自举编译器.agb`；不含 `自举/*.agl`、`tests/`、`editor/`，不跑 40 秒自举链；
- **开发者源码树/完整包**：保留 `自举/`、`tests/`、`editor/`，跑完整 27 项。

那个 `.agb` 是 `aglc` 编译 `.agl` 时用的引擎文件，不是让用户读或改的源码；用户只写 `.agl`。

### 在线安装（普通用户）

```powershell
python -m pip install "https://github.com/SiyanHaven/AGL/releases/download/v0.53.0/agl_lang-0.53.0-py3-none-any.whl"
aglc doctor
```

只下载 433 KB 的运行时 wheel，不 clone 仓库、不下载自举源码。

看到 **5 项全部通过（运行时包）** 即安装完成。首次 `run`/`build` 把内置 `.agb` 复制到 `~/.agl`（可用 `AGL_HOME` 改位置），不写 `site-packages`，不下载自举源码。

### Release 压缩包（离线/普通用户）

把 `AGL-v0.53.0.zip` 解压到本机任意目录（下文记为 `<AGL 目录>`），在该目录中执行：

```powershell
.\aglc.cmd doctor
```

期望 **5 项全部通过（运行时包）**。压缩包是干净的运行时形态，不含 `tests/`、`自举/`、`editor/`、开发脚本或设计规划文档；`aglc.cmd` 自动设置 `PYTHONPATH`。

### MCP 接入

当前 MCP 事实：服务器 `agl-mcp`，版本 **0.53.0**（跟随 `spec/keywords.toml`），协议 **2024-11-05**，工具 **10 个**：

`agl_card`、`agl_check`、`agl_check_source`、`agl_build`、`agl_run`、`agl_run_source`、`agl_convert`、`agl_summary`、`agl_version`、`agl_doctor`。

在线安装后直接启动，不需要 `cwd`：

```jsonc
{
  "command": "aglc",
  "args": ["mcp"]
}
```

压缩包形态则指向解压目录：

```jsonc
{
  "command": "python",
  "args": ["-m", "compiler.cli", "mcp"],
  "cwd": "<AGL 目录>"
}
```

自检：`python -m compiler.mcp --version` → `agl-mcp 0.53.0（协议 2024-11-05）`；
`python -m compiler.mcp --list` → 10 个工具。

## 五、明确边界（发布时必须知道）

- **不捆绑 Python**：运行依赖用户 agent 的 Python 3.10+；这不是安装器，也不是单文件 exe。
- **`工具` 声明只做语法与静态 schema 导出**，尚未接入真实 MCP 调用器；`aglc tools` 能导出 `name/description/inputSchema`，但 `工具` 不会生成运行期调用代码。
- **VM 不是 Python 全量替代**：超出 AGB 子集的程序要用 `--backend py` 显式兜底。
- **FFI 需要白名单**：`--allow-tools`，且只允许显式 `导入 外部` 的库。
- **HTTP 服务是常驻阻塞调用**：适合单独进程/任务，不适合在短脚本主流程里随手起。
- **用户包自带预编译自举器**：普通用户不需要 `aglc bootstrap`，首次 `run`/`build` 自动复制内置 `.agb`；`--compiler seed` 仍是显式回退。
- **没有代码签名/安装器/自动更新**：当前交付形态是源码目录 + `aglc.cmd` + WinForms 桌面 exe。
