# AGL 路线图

## 0.53.0 当前状态

- 中文/英文双分支语言与编译器；
- AGL 自举编译器（发布包内为预编译 `.agb`）；
- 自研 VM、AGB 字节码、效应与工具白名单；
- 模块、异常、匹配、任务、HTTP、FFI；
- MCP 工具服务器；
- 中英双语规范与六个可运行示例。

## 后续版本

1. **工具运行时**：把 MCP 工具调用从元数据/声明推进到真实调用与权限审计。
2. **VM 资源治理**：内存上限、更细粒度熔断、长任务配额。
3. **分发**：安装器、代码签名、跨平台启动脚本。
4. **编辑器体验**：更完整的诊断、补全和跳转。
5. **包管理**：标准库版本锁定与依赖解析。

## 不在当前版本

- 不承诺兼容任意 Python 语法；
- 不提供商业 SLA 或私有咨询；
- 不做无审核的任意外部命令执行。

路线图会随版本调整；具体能力以当前规范、`aglc doctor` 和发布说明为准。
