# AGL v0.54.0 发布说明

发布日期：2026-11-19

本版完整说明见 [`发布说明-v0.54.0.md`](发布说明-v0.54.0.md)；上一版见
[`发布说明-v0.54.0.md`](发布说明-v0.54.0.md)。

AGL 是一套可编译、可执行、可自举的中文/英文同构语言工具链：

```agl
#语言=中文
函数 主入口() {
  打印("你好 AGL")
}
```

## 这一版提供

- 中文、英文两套关键字，同一逻辑可以双向转换；
- 词法、语法、类型、效应、模块检查；
- `.agl` 源码编译为 `.agl.ir` 与 `.agb` 字节码，再由自研 VM 执行；
- 运行错误回译到 AGL 源码行号；
- **`工具` 声明的真实 MCP 运行时**：白名单、超时重试、重复调用熔断；
- 模块、结果对象、异常、`匹配`、任务、状态快照、HTTP、FFI（白名单）等能力；
- 192 个内建函数；
- 中英双语语言规范、入门教程、六个可运行示例。

## 安装

### 在线安装

```powershell
python -m pip install "https://github.com/SiyanHaven/AGL/releases/download/v0.54.0/agl_lang-0.54.0-py3-none-any.whl"
aglc doctor
```

期望：**5 项全部通过（运行时包）**。

### 离线包

把 `AGL-v0.54.0.zip` 解压到任意目录，在该目录执行：

```powershell
.\aglc.cmd doctor
.\aglc.cmd init 我的Agent
.\aglc.cmd run 我的Agent\main.agl
```

## 已知边界

- 不承诺兼容任意 Python 语法；
- 外部库调用需要显式效应声明，并受工具白名单限制；
- HTTP 服务是常驻阻塞调用，不适合短脚本主流程；
- 当前没有安装器、代码签名或自动更新。
