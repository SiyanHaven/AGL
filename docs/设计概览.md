# AGL 设计概览

AGL（Agent Grounded Language）是一门面向 AI 生成、同时要求人类可审查的声明式语言。它把“AI 要做什么、会碰什么、错在哪”变成可检查的源码结构。

## 设计目标

- 固定关键字：中文、英文两套写法语义对等，标识符、字符串、注释不翻译。
- 显式类型：变量、函数参数、返回值都写类型，减少隐式转换。
- 显式效应：读文件、联网、调用外部程序必须声明，纯函数不能偷偷产生副作用。
- 源码行号诊断：编译期和运行期的错误都指回 `.agl` 文件与行号。
- 可读优先：让不写代码的人也能审阅 AI 生成的程序。

## 编译与执行

```text
.agl 源码
  → 词法分析
  → 语法分析
  → 类型 / 效应 / 模块检查
  → IR
  → AGB 字节码
  → AGL VM 执行
```

默认编译器由 AGL 自己编写，发布包内是预编译的 `compiler/_runtime/自举编译器.agb`；Python 种子编译器保留为显式回退，用于对照和排障。

## 主要目录

```text
compiler/   编译器、检查器、IR、AGB、VM、CLI
aglc/       审计等辅助工具
spec/       关键字表、IR schema
stdlib/     用 AGL 编写的标准库
examples/   中英双语可运行示例
docs/       语言规范、入门教程、安装说明
```

## 能力边界

- AGL 不是 Python 的替代品，不承诺兼容任意 Python 语法。
- 外部库调用需要显式声明效应，并受工具白名单限制。
- HTTP 服务是常驻阻塞调用，不适合塞进短脚本主流程。
- 当前发布形态是运行时包和源码树，不包含安装器、代码签名或自动更新。

## 发布形态

- 普通用户：运行 `aglc`，只写 `.agl`，不需要看或改编译器源码。
- 开发者：从 GitHub clone 源码树，使用编译器源码、自举源码和编辑器扩展。

语言规范见 [SPEC.zh.md](SPEC.zh.md) / [SPEC.en.md](SPEC.en.md)，安装与命令见 [安装与更新.md](安装与更新.md)。
