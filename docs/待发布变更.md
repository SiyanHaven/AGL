## 2026-11-16：可编程网页应用

### 新增语言能力

`启动网页应用(端口, 处理函数名, 绑定地址?)`（英文 `web_serve`）：

- 效应为 `网络`，由 VM 和 Python 种子后端共同实现；
- 绑定地址可省略，默认 `127.0.0.1`（只接受本机访问）；需要局域网访问时显式传
  `"0.0.0.0"`，并自行考虑鉴权；
- 每个 HTTP 请求构造一个请求映射表，交给同模块中指定名称的 AGL 函数；
- 处理函数返回响应映射表，也允许直接返回文本；
- 支持 `GET` / `POST` / `PUT` / `PATCH` / `DELETE` / `HEAD`，`OPTIONS` 由运行时处理；
- 内置表单解析、JSON 序列化、CORS、`Content-Length` 和统一 `500` 异常响应；
- 返回映射表或列表时默认使用 `application/json`。

请求映射表：

| 键 | 含义 |
|---|---|
| `方法` | HTTP 方法 |
| `路径` | 解码后的路径 |
| `原始路径` | 带查询串的原始请求行 |
| `查询` | 查询参数映射表，同名参数取最后一个值 |
| `查询串` | 原始查询串 |
| `Cookie` | Cookie 请求头解析后的键值映射表 |
| `请求体` | 请求体原文 |
| `表单` | `application/x-www-form-urlencoded` 表单字段 |
| `头` | 请求头映射表 |
| `内容类型` | `Content-Type` |

响应映射表：

| 键 | 含义 |
|---|---|
| `状态` | HTTP 状态码，默认 `200` |
| `类型` | `Content-Type`；不写时自动判断 |
| `内容` | 文本，或自动序列化的映射表 / 列表 |
| `文件` | 要返回的文件路径，按二进制读取并自动推断 MIME |
| `头` | 额外响应头 |

### 相关实现

- `compiler/webapp.py`：可编程 HTTP 服务运行时，标准库实现，无第三方依赖；
- `compiler/vm.py`：VM 侧内建注册与处理函数调用；
- `compiler/backend_py/__init__.py`：Python 种子后端内建；
- `spec/keywords.toml`：新增 `启动网页应用` / `web_serve` 规格；
- `自举/内建表.agl` 与 `自举/字节码.agl`：自举侧内建表与规范名映射；
- `docs/网页应用.md`：请求 / 响应契约与完整案例说明；
- `docs/标准与契约.md`：服务内建一行同步更新。

### 一并修正

`打开数据库` 的规格写的是返回 `结果`，此前种子后端实际直接返回连接对象。
现在统一返回 `结果`，SQL 执行函数同时兼容 `取到(结果)` 和直接传连接两种写法，
留言板示例按标准 `结果` 流程编写。

### 已知边界

- 单进程、同步处理；没有并发连接池、TLS、登录会话、权限控制；
- 没有内置静态目录映射、模板引擎和 HTML 自动转义，页面仍由 AGL 返回字符串；
- `文件` 响应可以返回单个二进制资源，但不会自动把整个目录暴露成静态站点；
- 不等于任意 Python 项目一键转 AGL：`aglc import` 仍只覆盖当前语言能表达的写法。

## 2026-11-17：网页服务补充

### 新增能力

- 请求映射表新增 `Cookie`：运行时把 `Cookie` 请求头解析成普通键值映射表；
- 响应映射表新增 `文件`：返回一个文件路径，运行时按二进制读取并自动推断 MIME；
  可以返回 CSS、JS、图片、字体等资源，适用于单个静态资源接口；
- 文件响应优先于 `内容`，仍然可以通过 `头` 覆盖额外响应头；
- 返回映射表 / 列表时如果没写 `类型`，默认按 `application/json` 返回。

## 2026-11-17：HTML / URL 字符串工具

### 新增内建

- `转义HTML(文本)` / `html_escape`：转义 `&`、`<`、`>`、`"`、`'`；
- `编码URL(文本)` / `url_encode`：按 URL 组件编码，空格为 `%20`，斜杠不保留；

## 2026-11-17：安全默认与审计修复

第三方审计针对公开仓库旧 HEAD `1851991`，其中几项与本地当前代码直接相关，已先修：

- **网页服务默认回环**：`compiler/webapp.py`、VM `_agl_web_serve`、种子后端
  `_agl_启动网页应用` 统一默认 `127.0.0.1`；旧的 `启动HTTP` / `启动待办Web`
  也不再默认绑定 `0.0.0.0`。`启动网页应用` 增加可选第三参 `绑定地址`，
  需要局域网访问时必须显式写 `"0.0.0.0"`。
- **待办 HTML 转义**：种子后端的待办页把数据库内容经 f-string 直插 HTML，
  现改为 `html.escape(str(...))`，修掉存储型 XSS。
- **获取网页协议限制**：只允许 `http` / `https`，拒绝 `file://` 等协议，
  避免直接读本机文件；没有做私网地址封禁，SSRF 风险仍需调用方自行控制。
- **BOM 兼容**：`compiler/cli/pipeline.py`、CLI 源文件读取、`modules.py`、
  `mcp.py` 的源码读取改为 `utf-8-sig`；带 UTF-8 BOM 的 AGL 源文件不再报
  “缺少语言声明”。

- **MCP 路径边界（部分）**：`compiler/mcp.py` 的 `_file` 与 `agl_build` 的 `out_dir`
  现在必须落在工作区内，默认工作区是启动服务器时的当前目录；需要更大范围时
  显式设置 `AGL_MCP_WORKSPACE`。`tool_run` 对 `.agb` 的效应/工具授权默认值
  仍未收紧，属于下一项。

- **CLI 默认全禁（D1）**：`aglc run` 不带 `--allow-effects` / `--allow-tools` 时默认
  不授权任何效应或外部库；要放行必须显式写 `IO`、`Net` 等，或写 `all`。示例脚本
  与测试中的可信运行点已显式补齐参数；普通用户运行带效应的程序也要显式补。
- **AGB 结构校验（D1）**：`compiler/bytecode.py` 的 `decode` 不再只看
  format/version，还校验 lang/module/entry、常量池与名字池、函数参数/效应/指令/
  行号数组长度、函数名重复、opcode 白名单、池下标、跳转目标、调用/TASK/
  TRY_BEGIN 结构。它拦的是伪造/损坏字节码的明显结构，不冒充沙箱。
- **异步任务效应告警（D3）**：`任务(异步函数())` 如果任务体声明了
  `读写/网络/计时/外部调用/模型`，而当前函数没有声明对应效应，新增
  `AGL-W-0401` 告警；任务体仍在自己的协程里运行，但不再静默放行。
- **自举行号（D8）**：根因修复。自举词法器 token 已带 `行`；语法分析器把每条
  语句的起始行写进 AST 的 `"行"`；中间表示把 `"行"` 带进 IR 语句；字节码生成器
  在 `编译语句` 开头设置 `函数状态["当前行"]`，115 处 `发射` 改用当前行。
  CLI 侧原来的 Python 行号回填已移除。无回填的自举产物实测
  `lines=[4,4,4,4,4,4,4]`，`1/0` 报第 4 行（函数 主入口）。
- **审计工具（D6）**：`aglc/audit.py` 增加 import 别名、`importlib.import_module` +
  `getattr` 字符串拼接的静态归一化；报告开头明示“启发式静态扫描，只覆盖 Python，
  动态反射可能漏报，不能当安全边界”。
- **安装校验（D10）**：README 与 `docs/安装与更新.md` 增加 SHA256 核对步骤，并说明
  目前没有 GPG 签名；没有公布哈希的 Release 视为未校验下载。
- **深嵌套解析（D11）**：递归下降解析器遇到约 900 层嵌套时，不再抛裸
  `RecursionError`，改为 `AGL-E-0206`，带文件和行号，提示拆中间变量。
- **环境变量（D12）**：`环境变量` 读取名称像凭证的变量（TOKEN/SECRET/KEY/
  PASSWORD/CREDENTIAL 等）时默认拒绝；宿主可用
  `AGL_ENV_ALLOW_SECRETS=NAME` 或 `all` 显式放行。
- **编辑器高亮（D13）**：语法高亮生成器从“只收 stage 1”改为收 stage ≤ 2，
  `入参/工具/智能体/规则/配置` 等已出现在 VSCode 语法文件里。
- **版本号兜底（D14）**：`cmd_info` 读不到 `keywords.toml` 时改用安装元数据，
  不再在源码里写死 `0.53.0`。
- **未处理**：D15（解析器一次只报第一个错）仍是已知体验限制；D2 的 MCP
  `tool_run` 默认授权也仍是下一项。
