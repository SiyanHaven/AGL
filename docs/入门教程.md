# AGL 入门教程

> AGL（Agent Grounded Language）是一门面向智能体的声明式语言，让不懂编程的人也能看懂 AI 要做什么。

---

## 1. 安装

AGL 是零依赖的纯 Python 实现，只要有 Python 3.10+ 就能跑。在线安装后用 `aglc`；解压包用 `.\aglc.cmd`。在发布包目录里执行：

```powershell
# 试试跑一个示例
.\aglc.cmd run examples/zh/00_最小程序.agl
```

---

## 2. 第一个程序

新建一个文件 `你好.agl`：

```agl
#语言=中文

函数 主入口() {
  打印("你好，AGL！")
}
```

运行它：

```bash
python -m compiler.cli run 你好.agl
```

输出：

```
你好，AGL！
```

## 3. 基本语法

### 变量

```agl
变量 名字: 文本 = "小明"
变量 年龄: 整数 = 18
变量 身高: 浮数 = 1.75
```

### 函数

```agl
函数 加(a: 整数, b: 整数) -> 整数 {
  返回 a + b
}

函数 主入口() {
  打印(加(1, 2))
}
```

### 条件判断

```agl
函数 主入口() {
  变量 年龄 = 18
  如果 年龄 >= 18 {
    打印("成年人")
  } 否则 {
    打印("未成年人")
  }
}
```

### 循环

```agl
函数 主入口() {
  循环 i 在 范围列表(5) {
    打印(i)
  }
}
```

### 列表

```agl
函数 主入口() {
  变量 名字列表 = ["张三", "李四", "王五"]
  循环 名字 在 名字列表 {
    打印(名字)
  }
}
```

### 映射表

```agl
函数 主入口() {
  变量 学生 = {
    "名字": "小明",
    "年龄": 18,
    "成绩": 95
  }
  打印(学生["名字"])
}
```

## 4. 常用内建函数

### 打印

```agl
打印("你好")
打印(1, 2, 3)
```

### 类型转换

```agl
转整数("123")
转浮数("1.5")
转文本(42)
```

### 列表操作

```agl
变量 列表 = [3, 1, 2]
排序(列表)
反转(列表)
打印(列表.长度)  // 用 .长度 属性，不是函数
最小值(列表)
最大值(列表)
```

### 字符串操作

```agl
转小写("Hello")
转大写("Hello")
去空白("  你好  ")
打印("你好".长度)  // 用 .长度 属性
```

## 5. 异步编程

AGL 原生支持异步：

```agl
异步 函数 抓网页(url: 文本) -> 文本 {
  返回 等待 获取网页(url)
}

函数 主入口() {
  变量 任务1 = 任务(抓网页("https://example.com"))
  变量 任务2 = 任务(抓网页("https://google.com"))
  打印("两个任务都在跑...")
  等待 任务1
  等待 任务2
}
```

## 6. 错误处理

用 `尝试/捕获` 处理错误：

```agl
函数 主入口() {
  尝试 {
    变量 内容 = 取到(读文件("不存在的文件.txt"))
    打印(内容)
  } 捕获(错) {
    打印("出错了：", 失败原因(错))
  }
}
```

## 8. CLI 命令

| 命令 | 功能 |
|---|---|
| `aglc run 文件名.agl` | 编译并运行 |
| `aglc check 文件名.agl` | 检查代码有没有错 |
| `aglc format 文件名.agl` | 格式化代码 |
| `aglc lint 文件名.agl` | 检查代码风格 |
| `aglc info` | 显示 AGL 基本信息 |
| `aglc list-builtins` | 列出所有内建函数 |
| `aglc examples` | 列出示例代码 |
| `aglc clean` | 清理临时文件 |
| `aglc doctor` | 安装自检 |
| `aglc --version` | 看版本号 |
