# AGL v0.54.0 发布说明

发布日期：2026-11-19

这一版的核心变化只有一句话：**`工具` 声明从"设计词"变成了真正的运行时能力**。
你在 AGL 里声明的工具，现在可以真的被调用、真的拿到结果，并且有白名单、有重试、有熔断。

```agl
#语言=中文
工具 天气 {
  配置 {
    协议 = "mcp"
    地址 = "http://127.0.0.1:8080/mcp"
    超时秒数 = 10
    熔断阈值 = 3
  }
  入参(城市: 文本)
  返回 文本
}

函数 主入口() 效应 外部调用 {
  打印(天气("杭州"))     // 编译成内建 `调用工具`，走真实 MCP 调用
}
```

## 本版新增

- **工具声明的真实运行时**：`工具名(实参…)` 在语义层降成内建 `调用工具` / `call_tool`，
  编译器自动把声明里的配置带进调用。Python 后端与 VM 共用同一套 MCP Streamable HTTP 客户端
  （`initialize` → `notifications/initialized` → `tools/call`，含会话 ID、SSE、超时、重试）。
  自举编译器同样把声明带进 IR，并能降出同一条内建调用。
- **VM 侧工具白名单**：`--allow-tools` 现在对 `call_tool` 真正生效。
  未放行的工具在发出任何网络请求之前就以 `AGL-RT-0094` 拒绝。
- **重复调用熔断**：按（工具名，规范化实参）算 SHA-256 指纹；瞬断类错误退避重试；
  同一指纹失败后下一次直接拒绝；同一工具累计失败到阈值后整工具熔断；成功后清零。
  阈值可按工具配置（`熔断阈值` / `fail_limit`），默认 3。
- **自检自身不再会挂死**：`doctor` 里 43 处子进程调用统一走带 180 秒超时的包装，
  超时返回码 124 并给出可读原因，不再让父进程无限等待。

## 本版修复

- 在 Python 3.10 上可用：新增 `compiler/tomlutil.py`，3.11 以上转发标准库 `tomllib`，
  3.10 走内置最小 TOML 读取器（含内联表、三引号块、转义顺序、裸键校验）。
- Windows 控制台编码：`python -m compiler.mcp --version` 在 `cp1252` 控制台上不再崩。
- 自举行号链路补全：词法行 → AST `"行"` → IR `"行"` → `函数状态["当前行"]` → 每次 `发射`，
  AGB 里带真实行表，运行期错误能指回 `第 N 行`。
- 源码规范自检把条件导入的 `tomllib` 视为标准库，不再误报第三方依赖。

aglc doctor

## 已知边界

- 工具协议目前只实现 `mcp`；`local-skill` 与 `acp` 仍是缺口。
- 熔断状态按一次程序运行计，不跨进程持久化。
- 外部库调用需要显式效应声明，并受工具白名单限制；默认全禁。
- HTTP 服务是常驻阻塞调用，不适合短脚本主流程。
- 当前没有安装器、代码签名或自动更新。
