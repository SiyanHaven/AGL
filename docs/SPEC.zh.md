# AGL 语言规范（中文）

> 版本：**0.53.0**　　发布日期：2026-11-15　　状态：当前版本规范
>
> 本文件描述 `v0.53.0` 已经实现并经过 `aglc doctor` 验收的语言表面。机器可读的权威来源是
> [`spec/keywords.toml`](../spec/keywords.toml)；当本文与关键字表冲突时，以关键字表和编译器实测为准。

## 1. 范围

AGL（Agent Grounded Language）是一门面向 AI 生成、同时要求人类可审查的声明式语言。
它用固定关键字、显式类型、显式效应和源码行号诊断，把“AI 写了什么、会碰什么、错在哪”变成
编译器可以检查的结构。

本规范覆盖：词法、类型、声明、语句、表达式、效应、校验块、模块、运行产物、诊断、MCP 入口。
不覆盖：编译器实现细节、编辑器插件 UI、当前版本尚未实现的工具调用运行时。

## 2. 源文件与词法

### 2.1 编码与分支

- 源文件必须是 UTF-8 文本，扩展名为 `.agl`。
- 第一行必须是分支声明：
  - 中文分支：`#语言=中文`
  - 英文分支：`#lang=English`
- 一个文件只能使用一个分支的关键字。中文文件里出现英文关键字，报 `AGL-E-0102`；反之亦然。
- 标识符、字符串、注释是作者的内容，**任何情况下都不翻译、不改写**。

### 2.2 注释与空白

```text
// 行注释
/* 块注释 */
```

空白和换行用于分隔语句；块一律使用 `{ }`。条件写在块之前，不写圆括号：

```agl
#语言=中文
函数 主入口() {
  变量 数量 = 3
  如果 数量 大于 0 {
    打印("有数据")
  }
}
```

### 2.3 标识符与关键字

- 标识符可使用 Unicode 字母、数字和下划线，不能以数字开头。
- 关键字保留，不能当作变量名、函数名、参数名或字段名。
- 内建函数名不是关键字；但重名时编译器优先使用用户自己的定义，因此不建议用内建名做变量名。
- 完整关键字表见本文件的关键字表；完整内建表用 `aglc card --lang zh` 或 `aglc list-builtins` 查看。

### 2.4 字面量

| 字面量 | 写法 | 说明 |
|---|---|---|
| 整数 | `42`、`-7` | 十进制；负数是一元负号加整数 |
| 浮数 | `3.14`、`1.2e3` | 小数点或科学计数法 |
| 布尔 | `真` / `假` | 英文分支 `true` / `false` |
| 空 | `空` | 英文分支 `null` |
| 文本 | `"你好"` | 双引号；支持常见转义 |
| 列表 | `[1, 2, 3]` | 元素类型应一致 |
| 映射表 | `{"键": 值}` | 键值对；空映射写作 `{}` |
| 集合 | `{1, 2, 3}` | 元素去重；空集合用 `建集合()` |
| 结构体实例 | `用户(编号: 1, 名字: "阿明")` | 命名字段构造 |

## 3. 类型

### 3.1 基本类型

| 中文 | 英文 | 含义 |
|---|---|---|
| `整数` | `Int` | 整数 |
| `浮数` | `Float` | 浮点数 |
| `布尔` | `Bool` | 真 / 假 |
| `文本` | `String` | UTF-8 文本 |
| `空` | `Null` | 空值类型 |
| `列表` | `List` | 列表；可写 `列表<整数>` 指定元素类型 |
| `映射表` | `Map` | 键值映射 |
| `集合` | `Set` | 去重集合 |
| `结果` | `Result` | 成功或失败；用 `成功(值)` / `失败(原因)` 构造 |
| `错误` | `Error` | 捕获到的错误对象 |
| `任意` | `Any` | 无法静态确定时的兜底类型 |

### 3.2 结构体

```agl
类型 用户 {
  编号: 整数
  名字: 文本
}
```

- 结构体用 `类型` 声明，字段逐行写 `字段名: 类型`。
- 构造必须使用命名字段：`用户(编号: 1, 名字: "阿明")`。
- 字段读取用点号：`甲.编号`。
- 未声明字段、缺字段、字段类型不匹配都会在编译期报错。

### 3.3 可空类型

- `T?` 表示可空类型，例如 `文本?`。
- 普通值可以赋给 `T?`；`空` 只能赋给 `T?`。
- `T?` 的值不能直接流进 `T`，否则报 `AGL-E-0301`。
- 当前版本不做跨分支的流敏感收窄；判空后仍需显式取出非空值。

### 3.4 类型推断与注解

- `变量 名字 = 表达式` 可以由右值推断类型。
- 函数参数、返回值、结构体字段建议显式写类型；显式类型会参与检查。
- 泛型容器写作 `列表<整数>`、`列表<用户>`；`结果<文本>` 可用于接口签名。

## 4. 声明

### 4.1 函数

```agl
#语言=中文
函数 相加(甲: 整数, 乙: 整数) -> 整数 {
  返回 甲 + 乙
}

函数 主入口() {
  打印(相加(2, 3))
}
```

- 入口函数必须叫 `主入口`（英文 `main`），程序从它开始执行。
- 有返回类型的函数，每个返回路径都必须给出该类型的值。
- 没有写返回类型的函数不要求返回值。
- 参数可以带默认值；调用时可用 `参数名: 值` 的命名实参。

### 4.2 变量与常量

```agl
#语言=中文
函数 主入口() {
  变量 计数 = 0
  常量 服务名 = "agl-api"
  打印(服务名, 计数)
}
```

- `变量` 可重新赋值；`常量` 不可重新赋值。
- 增广赋值可用：`+=`、`-=`、`*=`、`/=`、`%=`。
- 解包赋值可用：`变量 甲, 乙 = [1, 2]`。

### 4.3 效应与校验

效应声明写在函数头与函数体之间，可放在校验块之前或之后：

```agl
#语言=中文
函数 读配置(路径: 文本) -> 文本
校验 {
  路径 不等于 ""
}
效应 读写
{
  返回 取到(读文件(路径))
}

函数 主入口() 效应 读写 {
  变量 内容 = 读配置("examples/zh/sample.log")
  打印(内容.长度)
}
```

- 效应标签：`读写` / `网络` / `模型` / `计时` / `外部调用`，英文 `IO` / `Net` / `model` / `Time` / `External`。
- 调用带效应的函数，调用方必须自己声明相同效应；否则报 `AGL-E-0401`。
- `校验` 块里的条件必须是可静态判断的比较或逻辑组合；不成立时运行期立即中断，并报告“校验失败：<条件原文>”。
- 校验块默认强制开启，不能关闭。

### 4.4 异步与外部调用

- `异步 函数` 声明异步函数；调用时用 `等待`。
- `任务(...)` 启动异步任务，可配 `当收到进度` / `当任务完成` / `当任务失败` 回调。
- `导入 外部 库名 [效应 ...]` 声明 FFI；外部库按最坏效应计算，除非显式声明更小效应。
- FFI 只做黑盒调用，不导入外部库源码。

### 4.5 模块、导入、导出

```agl
#语言=中文
模块 图书库

导出 函数 折后价(原价: 浮数, 折扣: 整数) -> 浮数 {
  返回 原价 * (1.0 - 折扣 / 100.0)
}
```

```agl
#语言=中文
导入 图书库

函数 主入口() {
  打印(图书库.折后价(100.0, 20))
}
```

- `模块 名字` 声明模块名；模块名就是文件名，不翻译。
- `导出` 决定模块外可见的声明；未导出的函数/类型不能被导入方使用。
- 导入方写 `导入 图书库`，调用写 `图书库.折后价(...)`。
- 模块内调用标准库时，模块自己也要写 `导入`，不能依赖主程序的导入。

### 4.6 接口与依赖

```agl
#语言=中文
接口 支付 {
  函数 付款(金额: 整数) -> 结果<文本>
}

函数 付款(金额: 整数) -> 结果<文本> {
  返回 成功("已付")
}

函数 主入口() {
  打印(付款(100))
}
```

- 接口只写签名；同文件必须存在参数、返回类型完全一致的实现。
- 依赖块的写法是 `依赖 { 工具包 = "1.2.0" }`；版本必须写成 `major.minor.patch` 字符串，源码依赖会与 `agl.toml [dependencies]` 对齐。

## 5. 语句

| 语句 | 中文写法 | 英文写法 |
|---|---|---|
| 条件 | `如果 条件 { } 否则 如果 条件 { } 否则 { }` | `if cond { } else if cond { } else { }` |
| 当循环 | `当 条件 { }` | `while cond { }` |
| 遍历 | `循环 每个 在 列表 { }` | `for item in list { }` |
| 返回 | `返回 值` | `return value` |
| 中断 / 继续 | `中断` / `继续` | `break` / `continue` |
| 匹配 | `匹配 (表达式) { 字面量 { } _ { } }` | `match (expr) { literal { } _ { } }` |
| 尝试 | `尝试 { } 捕获 (错) { } 最后 { }` | `try { } catch (e) { } finally { }` |
| 类型化捕获 | `捕获 (错: 下标越界)` | `catch (e: IndexError)` |
| 使用 | `使用 表达式 作为 名 { }` | `with expr as name { }` |
| 等待 | `等待 异步调用()` | `await async_call()` |

`匹配` 的模式当前只支持字面量和 `_` 通配符；没有匹配臂且没有 `否则` 时不执行任何分支。

## 6. 表达式与运算符

### 6.1 比较与逻辑

| 中文 | 英文 | 含义 |
|---|---|---|
| `等于` | `==` | 相等 |
| `不等于` | `!=` | 不等 |
| `大于` | `>` | 大于 |
| `小于` | `<` | 小于 |
| `大于等于` | `>=` | 大于等于 |
| `小于等于` | `<=` | 小于等于 |
| `并且` | `&&` | 逻辑与，短路 |
| `或` | `||` | 逻辑或，短路 |
| `非` | `!` | 逻辑非 |

算术运算符沿用常见写法：`+` `-` `*` `/` `%`；比较和逻辑优先使用上表的关键字写法。

### 6.2 成员、下标与调用

- 列表、文本、映射表、集合的长度用只读属性 `.长度`（英文 `.length`）。
- 列表/文本下标用 `[i]`，从 0 开始；映射表用 `[键]`。
- 函数调用用 `名字(实参...)`；模块调用用 `模块.函数(...)`；结构体字段用 `值.字段`。
- `调用(fn_ref, args...)` 可按函数引用动态调用；函数引用是 `[函数名, 捕获...]` 形式。

## 9. 模块与工程

### 9.1 `agl.toml`

```toml
[project]
name = "my-agent"
version = "0.1.0"
entry = "main.agl"
language = "zh"

[dependencies]
"数学" = "0.1.0"
```

- `entry` 指向入口文件；`language` 是 `zh` 或 `en`。
- `[dependencies]` 记录项目依赖；源码 `依赖` 块必须与它一致。
- 工程内的模块按文件名解析；导入路径不写扩展名。

### 9.2 标准库

当前标准库模块：`数学`、`列表工具`、`文本工具`、`日期工具`、`统计工具`、`加密工具`、`单位转换`。
标准库用 AGL 自身编写，纯函数、零效应；调用前在 `agl.toml` 声明依赖，并在源文件写 `导入`。

## 10. 运行模型与产物

- `aglc check <文件>`：词法、语法、语义、效应、模块检查，不产出文件。
- `aglc build <文件>`：默认使用自举编译器，产出 `<名>.agb`（AGB 字节码）和 `<名>.agl.ir`。
- `aglc run <文件>`：编译并交给默认 VM 执行；运行期错误回译到 AGL 文件、行号、函数。
- `.agb` 可以直接运行：`aglc run <文件.agb>`。
- `--compiler seed` 回退 Python 种子编译器；`--backend py` 是显式的 Python 后端兜底，不是默认路径。
- VM 支持效应白名单：`--allow-effects IO,Time,Net,External`；不在白名单的效应报 `AGL-RT-0092`。
- 默认 VM 有步数上限和墙钟超时；超时报 `AGL-RT-0091` / `AGL-RT-0095`。

## 11. 诊断

诊断码分区：

| 区间 | 类别 |
|---|---|
| `AGL-E-01xx` | 词法 |
| `AGL-E-02xx` | 语法 |
| `AGL-E-03xx` | 语义 / 类型 |
| `AGL-E-04xx` | 效应 / 校验 |
| `AGL-E-05xx` | IR / 转译 |
| `AGL-E-06xx` | 模块 / 配置 |
| `AGL-RT-00xx` | 运行时 |

结构化诊断至少包含：错误码、严重级别、中文原因、AGL 文件行号列号、调用栈、效应、修复建议。
`message_zh` 不出现宿主语言术语；宿主异常原因放在 `cause` 字段。

## 13. 版本与兼容

- 语言版本遵循语义化版本 `major.minor.patch`；当前权威值是 `spec/keywords.toml` 的 `meta.version`。
- `pyproject.toml`、`agl-mcp`、MCP `languageVersion` 必须与这个值一致。
- 新增关键字、类型、效应或改变语义属于 minor/major 变更；只修错误与文档属于 patch。
- 旧版本生成的黄金产物不作为长期兼容承诺；发布前必须重新跑 `doctor` 刷新。

## 14. 已知边界

以下能力在当前版本**没有**实现，不应在宣传或示例中暗示可用：

- 元组、类、继承、泛型函数、闭包、lambda、一等函数值；
- 跨分支的流敏感空值收窄；
- 真实 MCP / local-skill / ACP 工具调用运行时（`工具` 块仍只是设计词）；
- 运行时 OS 级沙箱；当前版本的安全边界是**编译期效应声明检查**，不是系统权限隔离；
- 重复调用熔断（仅有设计，尚未实现）；
- 标准库版本锁定与包管理器。
