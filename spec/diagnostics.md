# AGL 诊断码表 v0.1

> **纪律**：错误码是**跨模块、跨 AI、跨版本**的稳定标识。任何模块只能用本表里的码；
> 新增可以（追加到对应区间末尾），**已有码的含义永远不许改**（否则历史日志与回归测试全废）。

## 编码规则

```
AGL-<类>-<四位号>
```

| 前缀 | 类别 | 产生时机 | 谁产生 |
|---|---|---|---|
| `AGL-E-01xx` | 词法错误 | M1 | 词法分析器 |
| `AGL-E-02xx` | 语法错误 | M2 | 语法分析器 |
| `AGL-E-03xx` | 语义 / 类型错误 | M3 | 语义检查器 |
| `AGL-E-04xx` | 效应错误 | M3 | 语义检查器 |
| `AGL-E-05xx` | IR / 转译错误 | M4 / M5 | IR 构建 / 后端 |
| `AGL-E-06xx` | 模块错误 | 编译期 | 模块解析器 / 语义检查器 |
| `AGL-RT-00xx` | 运行时错误 | 执行期 | `aglc run` 错误回译层（§4.5） |

## 一、词法错误（AGL-E-01xx）

| 码 | 中文消息模板 | 触发条件 | fix_hints 建议 |
|---|---|---|---|
| `AGL-E-0101` | 文件第一行缺少语言声明。请写 `#语言=中文` 或 `#lang=English` | 首行不是语言声明 | 补首行声明 |
| `AGL-E-0102` | 中文分支里出现了英文关键字 `{kw}`，本文件已声明为中文 | `#语言=中文` 但出现英文关键字 | 换成对应中文关键字；或改首行声明 |
| `AGL-E-0103` | 字符串没有闭合，从第 {line} 行第 {col} 列开始 | 到行尾/文件尾仍未遇到闭合引号 | 补引号 |
| `AGL-E-0104` | 无法识别的字符 `{ch}` | 出现词法不认识的字符 | 检查是否有全角符号未归一（§3.13） |
| `AGL-E-0105` | 数字格式不合法 `{text}` | 如 `1.2.3`、`12abc` | 修正数字 |
| `AGL-E-0106` | 关键字 `{kw}` 在当前阶段未启用（需阶段 {stage}） | 用了扩展关键字但阶段未到（§3.2.1） | 改用基础写法，或等待阶段升级 |
| `AGL-E-0107` | 字符串里有无法识别的转义 `\{ch}`：AGL 只认 `\\` `\"` `\n` `\t` `\r` | 字符串里出现表外转义（如 `\U`、`\d`、`\0`） | 想写反斜杠就写 `\\`；换行用 `\n`，制表用 `\t` |
| `AGL-E-0108` | `_` 是保留字（§3.3 匹配通配符 / 丢弃绑定），不能当变量名或参数名 | 把 `_` 用作标识符 | 换一个有意义的名字 |
| `AGL-E-0109` | AGL 用换行分隔语句，`;` 只能写在语句末尾（可省略），这里一行中间又写了 `;` | 行中再写 `;` 拆语句 | 删掉 `;`，用换行拆成两行 |
| `AGL-E-0110` | 块注释 `/* … */` 没有闭合 | `/*` 后没有配对的 `*/` | 补上结尾的 `*/` |

## 三、语义与类型错误（AGL-E-03xx）

| 码 | 中文消息模板 | 触发条件 | fix_hints 建议 |
|---|---|---|---|
| `AGL-E-0301` | 类型不匹配：这里是 `{want}`，但给的是 `{got}` | 类型检查失败 | 转换或修改 |
| `AGL-E-0302` | 使用了未声明的名字 `{name}` | 标识符未定义 | 检查拼写 / 补声明 |
| `AGL-E-0303` | `{name}` 是常量，不能重新赋值 | 对 `常量` 赋值 | 改为 `变量` |
| `AGL-E-0304` | 变量 `{name}` 在使用前没有初始化（§3.5） | 声明未赋值即使用（预留，暂未使用） | 声明时赋值 |
| `AGL-E-0305` | 文本与数字不能直接比较（§3.11） | `"a" > 1` 之类 | 显式转换 |
| `AGL-E-0306` | 名字 `{name}` 在本作用域外不可见（§3.4 遮蔽） | 作用域错误（预留，暂未使用） | 提前声明或改名 |
| `AGL-E-0307` | 函数名重复：`{name}` | 同一文件里定义了两次同名函数 | 给其中一个改名 |
| `AGL-E-0308` | 找不到入口函数：`{entry}` | 入口文件没有程序起点函数 | 补 `函数 主入口() { … }` |
| `AGL-E-0309` | `{name}` 需要 {expect}参数，这里给了 {n} 个 | 内建函数实参个数不符 | 按 usage 补齐或删减 |
| `AGL-E-0310` | `{name}` 的第 {i} 个参数要{want}，这里给的是{got} | 内建函数实参类型不符 | 按 usage 转换参数 |
| `AGL-E-0311` | `等待` 只能写在异步函数里（§3.6） | 同步函数里写了 `等待` | 把函数改成 `异步 函数` |
| `AGL-E-0312` | `{name}` 要写 `等待 {name}(…)` | 调用了需要等待的内建 / 异步函数但没写 `等待` | 在前面补 `等待` |
| `AGL-E-0313` | 入口函数 `{entry}` 不能有参数（程序起点没有调用方） | 入口函数声明了形参 | 删掉入口函数的参数 |
| `AGL-E-0314` | `{name}` 不是类型。当前版本 的类型只有 AGL 内建类型（整数 / 浮数 / 真假 / 文本 / 空 / 列表 / 映射表 / 结果 / 错误 / 任意），自定义类型还未实现 | 类型注解里出现表外名字（如拼错的 `字符串`） | 改用 AGL 内建类型 |
| `AGL-E-0315` | `任务()` 的参数要是一个异步调用，如 `任务(睡眠(10))` 或 `任务(慢())`；传普通值没有意义 | `任务()` 传了普通值（如 `任务(1)`） | 把要跑的异步操作写进 `任务(…)` |
| `AGL-E-0316` | `等于` / `不等于` 两侧类型差太远（{left} 和 {right}），它们不可能是同一个值 | 文本×数字 / 真假×数字 / 真假×文本 用 `==`/`!=` 比较 | 把两侧转成同一种类型再比 |

## 七、运行时错误（AGL-RT-00xx）—— §4.5 错误回译层

> **这一组是给普通人看的**。`message_zh` 必须说人话，禁止出现 `AttributeError`、`NoneType`、`traceback` 这类词。

| 码 | 中文消息模板（给人看） | 典型原因 | fix_hints 建议 |
|---|---|---|---|
| `AGL-RT-0001` | 程序意外停止，原因见下 | 未分类异常 | 看 `cause` 字段 |
| `AGL-RT-0007` | 这里是空值，读不到它的 `{field}` | 空值访问 | 先判断是否为空；或补 `校验` |
| `AGL-RT-0008` | 这个{类型}没有 `{field}` 这个成员 | 成员名写错，或用了语言没提供的属性 | 检查拼写；文本/列表/映射表目前只提供 `.长度` |
| `AGL-RT-0010` | 不能除以零 | 除零 | 检查除数 |
| `AGL-RT-0020` | 列表只有 {len} 项，取不到第 {index} 项 | 越界 | 检查索引范围 |
| `AGL-RT-0021` | 映射表里没有键 `{key}` | 缺失键 | 用默认值或先判断 |
| `AGL-RT-0030` | 网络请求失败：{detail} | 连接失败 / 超时 | 重试；或补错误分支 |
| `AGL-RT-0031` | 网络请求返回了错误状态 {code} | HTTP 4xx/5xx | 检查地址与凭证 |
| `AGL-RT-0040` | 文件不存在：{path} | 路径错误 | 检查路径；先判断存在 |
| `AGL-RT-0041` | 没有权限访问：{path} | 权限不足 | 换路径或以更高权限运行 |
| `AGL-RT-0050` | 调用的外部命令退出码 {code}：{detail} | 子进程失败 | 看命令输出 |
| `AGL-RT-0060` | 大模型调用失败：{detail} | API 错误 / 额度不足 | 检查密钥与额度 |
| `AGL-RT-0070` | 找不到外部库 `{lib}`：它需要先在环境里装好才能用 | FFI 库没装 / 导入失败 | 先装好这个库，或换一个已经装好的 |
| `AGL-RT-0071` | 外部库 `{lib}` 里没有 `{method}` 这个方法 | FFI 方法名写错 | 查一下这个库的方法名怎么拼 |
| `AGL-RT-0072` | 调用外部库 `{lib}.{method}` 时出错：{reason} | FFI 调用抛了异常 | 看看这个外部方法要什么参数、什么输入 |
| `AGL-RT-0091` | 执行步数超过上限 {max_steps}（可能是死循环） | VM 指令预算耗尽 | 加终止条件，或显式调大 `max_steps` |
| `AGL-RT-0092` | 调用 `{name}` 需要 `{effect}` 效应，但当前未授权 | 宿主未放行该效应 | 在 `--allow-effects` 里显式放行，或删掉该调用 |
| `AGL-RT-0093` | 外部调用次数超过配额 {max_calls} | 带效应的内建/FFI 调用超限 | 减少外部调用，或显式调大 `max_calls` |
| `AGL-RT-0094` | 外部库 `{lib}` 不在允许列表 | FFI 库未获授权 | 在 `--allow-tools` 里显式列库 |
| `AGL-RT-0095` | 执行时间超过上限 {timeout_ms} 毫秒（可能是死循环或外部调用阻塞） | 墙钟超时 | 加终止条件，或显式调大 `--timeout-ms` |
| `AGL-RT-0099` | **无法定位到 AGL 源码**，这里是原始错误信息：{host_error} | 回译失败（§4.5.5 兜底） | 上报该样例用于补映射 |

## 七、结构化输出格式（`--诊断=json`）

所有诊断，无论编译期还是运行期，JSON 形态统一为：

```json
{
  "code": "AGL-E-0401",
  "severity": "error",
  "message_zh": "纯函数「相加」调用了带效应「网络」的函数「取数」",
  "agl": { "file": "main.agl", "line": 12, "col": 9, "end_col": 17 },
  "stack": [],
  "effects": ["Net"],
  "cause": null,
  "fix_hints": [
    { "kind": "add_effect", "at": "main.agl:8", "suggest": "给「相加」补 `效应 网络`" }
  ]
}
```

字段要求：

| 字段 | 必填 | 说明 |
|---|---|---|
| `code` | ✅ | 本表里的码 |
| `severity` | ✅ | `error` / `warning` |
| `message_zh` | ✅ | 中文人话，**不许出现宿主语言术语** |
| `agl` | ✅ | 必须指向 AGL 源码位置 |
| `stack` | ✅ | 运行时错误的 AGL 调用栈；编译期为 `[]` |
| `effects` | ✅ | 相关效应标签（英文规范名） |
| `cause` | ✅ | 宿主侧原始原因，仅排查实现问题时用；可 `null` |
| `fix_hints` | ✅ | **AI 自循环修复靠这个字段**，可空数组但不能缺字段 |
