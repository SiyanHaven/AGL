# AGL Examples

These are the published examples for AGL **v0.53.0**: six complete examples plus a minimal
program. They are not throwaway snippets: each example is checked, compiled to `.agb`, and
executed on the default VM by [`run_examples.py`](run_examples.py).

## Run everything

From the extracted release root:

```powershell
python examples/run_examples.py
```

Expected result:

```text
EXAMPLES OK: 6/6 (check + build .agb + VM run)
```

If this is a fresh release archive, the bundled precompiled compiler is used directly; it does not
rebuild the self-hosted compiler.

## Build once, run `.agb`

```powershell
python -m compiler.cli build examples/zh/01_销售日报.agl --out build/examples
python -m compiler.cli run build/examples/01_销售日报.agb
```

`build` produces `<name>.agb` and `<name>.agl.ir`. No `.py` is generated by default. Add
`--compiler seed` only when explicitly testing the Python seed compiler, and `--backend py` only
when an example needs functionality outside the AGB/VM subset.

## Design rules for examples

- No third-party packages, no network dependency, no local absolute paths.
- File examples use the bundled `sample.log` and print a stable result.
- Every example is deterministic so it can be used in CI.
- `examples/` is demonstration code, not a test fixture. Do not put compiler internals here.
