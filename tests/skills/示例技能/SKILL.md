# 示例技能：求和

这是一份给 `协议 = "local-skill"` 用的最小技能包说明。运行时只会用到同目录的入口脚本，
本文件供人阅读。

## 调用约定

- 入口脚本从 stdin 读一行 JSON：`{"tool": 工具名, "arguments": 实参映射表, "config": 配置映射表}`
- 成功时退出码为 0，stdout 输出 JSON 或纯文本
- 失败时退出码非 0，stderr 写原因（运行时会把它带进报错信息）
- 超时按配置的 `超时秒数` 计算，超时视为可重试的瞬断

## 入口

同目录的 `run.py`，不写 `入口` 时运行时会按 `run.py` / `main.py` / `run.cmd` / `run.ps1` 依次探测。
