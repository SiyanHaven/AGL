# 自举源码

这个目录里是用 AGL 语言本身编写的编译器源码。

| 文件 | 作用 |
|---|---|
| `词法器.agl` | 源码 → 记号流 |
| `语法分析器.agl` | 记号流 → 语法树 |
| `中间表示.agl` | 语法树 → 中间表示 |
| `字节码.agl` | 中间表示 → AGB 字节码 |
| `编译器.agl` | 最小编译闭环示例 |
| `自举编译器.agl` | 词法 → 语法 → IR → 字节码的完整入口 |
| `内建表.agl` | 内建函数表 |
| `校验器.agl` | 自举侧静态校验 |

构建自举编译器：

```powershell
aglc bootstrap
```

该命令用 Python 种子编译器生成第一版，再让 AGL 编译器编译自身，最后安装为运行时使用的 `自举编译器.agb`。
